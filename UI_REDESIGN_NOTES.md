# MI6 Black File UI Redesign

This build keeps the simulation engine, causal tree, save/load system and narration logic intact while replacing the main interface with a new responsive MI6 / cinematic dossier theme.

## Main changes
- Complete layout rebuild with a sticky MI6 command header and responsive mission workspace.
- New black, brass-gold, oxblood and steel-blue visual system.
- Rebuilt actor and film selection cards with larger typography and clearer information hierarchy.
- New cinematic simulation-frame hero with a CSS gun-barrel motif.
- Rebuilt tactical recon strip for location, threats and gathered intel.
- Narrative sections now read as separate classified dossier cards.
- Decision choices moved into a dedicated decision console with numbered action cards.
- Custom actions upgraded from a single-line input to a proper multi-line directive field.
- Reworked launch screen and mission summary/debrief screens.
- Actor radar comparator restyled and simplified.
- Audio Recon controls rebuilt to match the new theme while retaining voice presets, replay controls and tuning.
- Save and causal-tree modal shells harmonized with the new visual language.
- Responsive behavior improved for laptop, tablet and mobile widths.

No simulation logic or API contracts were intentionally changed.
